# Práctica 1 · Clonar

```bash
git clone https://github.com/japarejo/guia-git.git
cd guia-git
git remote -v
git status
```

**Comprueba:** `git status` dice `On branch main` y `nothing to commit, working tree clean`. Pega esa salida en el chat.

Si `git clone` pide usuario y contraseña, la contraseña es tu **token**, no la de tu cuenta.
