# Práctica 2 · Tu primer commit

1. Copia la plantilla: `cp participantes/plantilla.md participantes/<tu-usuario>.md`
2. Rellena tu ficha y guarda.
3. Mira el estado: `git status` (tu archivo aparece en rojo, *untracked*).
4. Prepáralo: `git add participantes/<tu-usuario>.md`
5. Guárdalo: `git commit -m "Añade la ficha de <tu-usuario>"`
6. Comprueba: `git log --oneline`

Repasa lo ocurrido con la animación [Las tres zonas de Git](https://japarejo.github.io/guia-git/animaciones/01-tres-zonas.html).
