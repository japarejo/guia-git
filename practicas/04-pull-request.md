# Práctica 4 · Abre, revisa, fusiona

## Abre tu pull request
1. `git push -u origin ficha-<tu-usuario>`
2. En GitHub, pulsa **Compare & pull request**.
3. Base: `main` ← tu rama. Escribe qué cambia y por qué.
4. En **Reviewers**, añade a la persona que te asigne el docente y pulsa **Create pull request**.

## Revisa la que te asignen
1. Abre la pull request y ve a **Files changed**.
2. Deja al menos un comentario en una línea.
3. **Review changes › Approve**.

## Fusiona la tuya
Cuando esté aprobada: **Merge pull request › Confirm merge › Delete branch**.

Si GitHub muestra *This branch has conflicts*, escríbelo en el chat.

Ver: [Del issue a main](https://japarejo.github.io/guia-git/animaciones/03-pull-request.html).
