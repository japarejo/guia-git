# Prepara el repositorio de tu equipo

## Una persona del equipo
1. Crea el repositorio: **New repository**, nombre del proyecto, marca *Add a README*.
2. **Settings › Collaborators › Add people**: invita al resto del equipo.
3. **Settings › Branches › Add rule** para `main`: *Require a pull request before merging* con 1 aprobación.
4. Copia [plantilla-README.md](plantilla-README.md) como README del proyecto.

## Cada miembro
1. Acepta la invitación (llega por correo o en github.com/notifications).
2. `git clone` del repositorio del equipo.
3. Abre una pull request que añada tu nombre a la tabla del README.

## Equipo listo cuando…
- [ ] Todos pueden hacer `git push` a una rama.
- [ ] `main` está protegida.
- [ ] Hay al menos tres issues con responsable.
- [ ] Cada miembro ha fusionado una pull request revisada por otra persona.

Pegad el enlace del repositorio en el chat al terminar.
